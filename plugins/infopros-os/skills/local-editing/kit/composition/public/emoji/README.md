# Video ad emoji

Noto Color Emoji artwork (googlefonts/noto-emoji, `2D/svg`, commit `e20cbc2bbec1`) for the icons a line of typed text can carry (`engine/types.ts` TEXT_ICONS). The composition draws them as images from its public folder, so every render shows the same color emoji whatever fonts the worker has. `OFL-noto-emoji.txt` is the repository's license; its README places the images under Apache 2.0.
